# 🎨 OmniPark Diagonal Images - v2.0.0

Solución profesional con Widget Elementor para crear galerías con corte diagonal.

## ✨ Características principales

✅ **Widget Elementor nativo** - Sin código, solo arrastra
✅ **Panel de control visual** - Personalización completa
✅ **Múltiples imágenes** - Agregar ilimitadas
✅ **Textos y colores personalizables** - Para cada imagen
✅ **Tipografías ajustables** - Fuente, tamaño, peso
✅ **5 ángulos de corte** - 10°, 15°, 20°, 25°, 30°
✅ **Efectos hover avanzados** - Zoom, elevación, grayscale
✅ **100% Responsive** - Mobile, tablet, desktop
✅ **Puro CSS** - Sin JavaScript pesado
✅ **Backward compatible** - Shortcode también disponible

---

## 🚀 Instalación rápida (3 pasos)

### 1️⃣ Descargar
- Descarga todos los archivos
- Ve a `/wp-content/plugins/`

### 2️⃣ Copiar
- Crea una carpeta: `omnipark-diagonal`
- Copia TODOS los archivos dentro

### 3️⃣ Activar
- WordPress → Plugins
- Busca "OmniPark Diagonal Images"
- Haz clic en "Activar"

## 🎯 Cómo usar (Lo básico)

1. **Edita una página en Elementor**
2. **Busca el widget "OmniPark Diagonal Images"**
3. **Arrastra al contenido**
4. **Agrega imágenes en el panel izquierdo**
5. **Personaliza: textos, colores, tipografías, etc.**
6. **¡Publica!**

---

## 🎨 Personalización disponible

### Diseño
- ✏️ Espacio entre imágenes (0-50px)
- ✏️ Altura de imágenes (100-600px)
- ✏️ Ángulo del corte diagonal (5 opciones)
- ✏️ Alineación (izq/centro/der)

### Estilos de Imagen
- 🎨 Sombra personalizada
- 🎨 Radio de borde
- 🎨 Efectos hover (Zoom, elevación, grayscale)

### Estilos de Texto
- 🔤 Tipografía completa (fuente, tamaño, peso)
- 🔤 Color del texto
- 🔤 Alineación
- 🔤 Espaciado (padding)

### Contenedor
- 📦 Color de fondo
- 📦 Espaciado personalizado

---

## 📱 Responsivo

El widget se adapta automáticamente:

- **Desktop (>1024px)** - Imágenes lado a lado
- **Tablet (768-1024px)** - Tamaño reducido
- **Mobile (<768px)** - Imágenes apiladas
