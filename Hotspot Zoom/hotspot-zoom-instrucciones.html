Zoom para Elementor Hotspot

1) En el widget Hotspot de Elementor agrega la clase: hz-hotspot-zoom

2) Copia el contenido de hotspot-zoom.css en tu CSS global.

3) Copia el contenido de hotspot-zoom.js en Custom Code (footer).

CDN usada por el script

https://unpkg.com/@panzoom/panzoom/dist/panzoom.min.js

Notas

  • El zoom escala imagen y hotspots juntos.
  • Incluye controles dentro de la imagen (esquina inferior derecha): +, -, Reset.
  • Tambien incluye wheel zoom, drag y doble clic para reset.
  • Soporta inicialización con render dinámico de Elementor.
  • Si necesitas subir solo la imagen sin mover los puntos, usa la variable CSS --hz-image-offset-y (por ejemplo: -12px).
